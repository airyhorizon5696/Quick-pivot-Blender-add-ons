# Quick Pivot Blender add-ons

Add-ons Blender qui place le pivot d'un objet en un clic, sans passer par le clic droit.

## Fonctions

- Grille 3 x 3 pour placer le pivot sur la boîte englobante (haut / milieu / bas, gauche / centre / droite)
- Centre de la boîte, bas au centre, centre de masse, centre du volume
- Pivot sur la sélection (mode édition), sur le curseur 3D ou à l'origine du monde
- Fonctionne sur plusieurs objets à la fois, et la géométrie ne bouge pas

## Installation

1. Télécharge `quick_pivot.py`
2. Blender > Edit > Preferences > Add-ons > Install from Disk
3. Coche l'addon, puis ouvre le panneau avec **N > Pivot**

Compatible Blender 3.0+ (testé sur 5.2).

# English

Blender addon that sets an object's pivot in one click, no right-click menus needed.

## Features

- 3 x 3 grid to place the pivot on the bounding box (top / middle / bottom, left / center / right)
- Box center, bottom center, center of mass, center of volume
- Pivot to selection (Edit Mode), to the 3D cursor, or to the world origin
- Works on multiple objects at once, and the geometry stays in place

## Installation

1. Download `quick_pivot.py`
2. Blender > Edit > Preferences > Add-ons > Install from Disk
3. Enable the addon, then open the panel with **N > Pivot**

Compatible with Blender 3.0+ (tested on 5.2).
